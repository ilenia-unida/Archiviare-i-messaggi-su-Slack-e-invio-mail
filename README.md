# Archiviare-i-messaggi-su-Slack-e-invio-mail
💬 Slack ➡️ Drive ☁️ + Gmail 📧 Automatizza l'archiviazione e l'invio di messaggi da Slack. Intercetta un messaggio su un canale, lo trasforma in un file di testo (TXT), lo carica su Google Drive e invia il file come allegato via Gmail. Ottimo per l'archiviazione di log o note veloci.
